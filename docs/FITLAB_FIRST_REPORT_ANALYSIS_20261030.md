# 무료 1차 리포트의 기기 내 간단 분석 — 2026-10-30

iOS와 Android는 기존 **사이즈 수치 비교 → 간단 분석 → 판매처 정보** 순서로 표시한다. 사이즈 범위와 사이즈 간 증감 수치는 첫 카드에 유지한다. 분석 근거인 판매처 소재·구조·핏·모델·관리 정보는 접지 않으며 상품 원문과 확인 시간을 제공한다. 상세 실측표의 기존 펼치기, 상품 정보 수정, 비교 버튼과 `실타래 1개가 소모됩니다.` 안내도 유지한다.

분석은 외부 AI API 없이 기기에서 계산한다. 소재 혼용률로 섬유의 일반적 성질을 짧게 설명하고, 지원하는 상의의 전체 사이즈표에서 가슴 단면과 총장 비율을 비교한다. 박시한 비율은 의류 형태에 대한 추정이며 개인에게 맞는 핏을 확정하지 않는다. 판매처 설명과 실측이 충돌하면 디자인 확인을 안내한다. 판단할 자료가 없으면 해당 분석을 생략한다.

이는 학습 모델이 아닌 초기 규칙이다. 임계값은 검증된 업계 표준이나 정확도 점수가 아니다. [공통 규칙 설명과 출처](../shared/fitlab/README.md)에 판단 조건과 한계를 기록했다. 공통 JSON에서 Swift/Kotlin 상수와 테스트 자료를 생성하며 CI가 동기화를 검사한다. 상품 정보·치수 수정 시 분석은 즉시 다시 계산한다. 서버 변경이나 재배포는 없다.

## 검증

- 독립적으로 작성한 공통 29개 사례: 소재 비율·별칭·불명확한 구성·판매처 설명 충돌·전체 사이즈 비율·수정 후 재계산을 두 실제 네이티브 구현으로 검사했다. 두 플랫폼의 최종 분석 문장 29개가 모두 일치했다.
- iOS: 단위 테스트 16개, 밝음/어두움 각각 UI 테스트 4개 통과.
- Android: 단위 테스트 92개, lint 및 앱/테스트 APK 빌드, 일반 밝음/좁은 어두움 각각 네이티브 테스트 2개 통과.
- 현재 바이너리에서 상품 정보 있음/없음, 직접 입력, 상품명 수정, 상세표 및 화면 끝 상태 32장을 캡처했다. 같은 입력의 수정 전 화면 32장과 비교했다. 로컬 증빙은 `.omo/evidence/product-narrative/`의 `final-captures.json`, `before-after-pairs.json`, `builds.json`, `parity.json`이다.
- 소재·핏의 긍정 경로는 통제된 상품 데이터로 검증했다. 실제 판매처의 접근 제한이나 수집 정책이 해소되었다는 의미는 아니다.
