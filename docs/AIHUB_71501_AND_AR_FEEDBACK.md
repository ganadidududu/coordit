# AR 피드백 및 AI Hub 실제 데이터 확보 (2026-10-28)

우선순위는 올바른 측정점과 실제 cm 정확도다. Phase 3는 변경하지 않았다. 실제 봉제선 모델과 cm 독립 정확도가 완성됐다고 주장하지 않는다.

## 촬영과 보정 수정

Layout: 기존 카메라 화면의 한 개 세로 스크롤을 유지한다. 라이브 카메라 안에 인식된 평면 경계와 준비 단계를 표시하고 촬영/직접 측정점 지정을 주요 동작으로 둔다. 결제·저장·보고서 흐름은 보존한다.

- 촬영 제한은 의류 인식 결과가 아니라 정상 트래킹·중앙 평면·이동 기준선·수직 구도·정지 상태였다. 어떤 조건이 부족한지 안내하지 않았던 문제를 수정했다.
- 공간 탐색 중에는 수직 구도를 요구하지 않고 같은 평면의 이동 기준선을 수집한다. 마지막 촬영 시 정상 트래킹·충분한 평면·이동 기준선·아래를 보는 구도·정지는 계속 검사한다. Apple 수평면 coaching도 추가했다.
- 공간 탐색 → 바닥 찾기 → 위치 이동 → 수직 구도 → 고정 → 촬영 가능 상태를 구분한다. 파란 경계는 현재 중앙 raycast의 실제 평면 경계이며 의류 인식 결과가 아니다. 다른 평면으로 바뀌면 재검증한다.
- 자동 점의 길이가 허용 범위를 벗어나도 보정점을 버리지 않는다. 드래그로 고칠 수 있지만 유효하지 않은 값의 저장·분석은 차단한다. 평면 밖 점은 임의로 외삽하지 않고 직접 지정/재탐색을 안내한다.
- 자동 인식 중에도 중단하고 직접 점을 지정할 수 있다. 취소 후 늦은 결과가 수동 점을 덮어쓰지 않는다. 점 한 개만 입력한 상태에서도 드래그할 수 있다.
- 카드 없는 AR의 인식용 이미지만 최대 1600px로 줄이고 카드 탐색을 생략한다. cm 기하 계산은 원래 촬영 프레임·내부 파라미터·포즈·평면을 계속 사용한다. 실제 폰의 지연 개선량은 아직 측정하지 않았다.
- 현재 폰의 자동 점은 윤곽 휴리스틱이다. 새 마스크 사전학습 가중치는 폰에 탑재하지 않았다. 윤곽이 잡혀도 봉제선은 실패할 수 있다.

재시험은 옷 주변의 무늬가 있는 바닥까지 천천히 위치를 옮겨 탐색 → 파란 영역 안에 옷을 포함 → 위에서 전체를 보며 고정 → 촬영 순서다. 실패하면 직접 점을 지정한다. 반복 촬영/줄자 비교가 필요하다. 시뮬레이터 테스트로 센서 cm 정확도를 증명할 수 없다.

수정된 실기기 빌드는 `/tmp/coordit-ar-feedback-device/Build/Products/Debug-iphoneos/coordit.app`에 있다. 이 작업에서 폰에는 재설치하지 않았다. 이전 빌드의 시험 기록이 메모리에 남을 수 있으므로 먼저 내보내야 한다. 운영 플래그는 바꾸지 않았다.

## 실제로 받은 데이터

[AI Hub 71501](https://www.aihub.or.kr/aihubdata/data/view.do?dataSetSn=71501)은 `의류 통합 데이터(착용 이미지, 치수 및 원단 정보)` v1.1이다. 전체 게시 수 550,634장/약 327GB를 다운로드한 것은 아니다.

사용자가 채팅 옆 브라우저에 로그인하고, 현재 다운로드 약정에 명시적으로 동의한 뒤 신청을 진행했다. 쿠키/비밀번호/API 키를 추출하지 않았다. 공식 브라우저에서 아래 파일을 받았다.

- 포맷 점검용 Sample.zip: 사진 12장 + JSON 12개. 별도 학습에 사용하지 않음.
- 공식 데이터 설명서 HWP와 구축·활용가이드 HWP. cm 계측법과 원본 촬영/참여자 계약 절차를 확인함.
- 코트 원천 ZIP(키 466492, 2,252,838,699 bytes), 대응 라벨 ZIP(466504, 14,074,338 bytes).
- 재킷 원천 ZIP(466493, 2,203,616,543 bytes), 대응 라벨 ZIP(466505, 12,858,727 bytes).

원천 TAR의 part0/part1073741824/part2147483648을 순서대로 병합해 게시 ZIP 크기와 CRC를 확인했다. 아카이브 SHA-256은 `ml/reports/AIHUB_71501_DOWNLOAD_PLAN.json`에 기록했다. 재구성용 중간 원천 파트 폴더는 복구 가능한 휴지통으로 옮겼고, 원본 다운로드 TAR·병합 ZIP·압축 해제 데이터는 유지했다.

## 숫자 정답의 정확한 의미

가이드는 의류 치수를 cm로 직접 계측한다고 명시한다. `metadata.model`의 착용자 신체 치수는 읽지 않는다. `metadata.clothes` 안의 의류 치수를 보존한다.

| 원본 항목 | 가이드의 측정 기준 | Coordit 연결 시 주의 |
| --- | --- | --- |
| 상의 앞길이 | HPS에서 밑단까지 앞중심선에 평행 | 총장 시작점/진행 방향 확인 |
| 가슴둘레 | 겨드랑이 약 2.5cm 아래 단면의 2배 | 현재 겨드랑이 랜드마크와 동일 지점이 아님 |
| 어깨너비 | 뒤쪽 양 어깨점 사이 수평 너비 | 앞면 사진의 점 정답으로 치환 금지 |
| 소매길이 | 어깨점부터 소매부리 하단 | 라글란/드롭숄더 기준 확인 |
| 팬츠 길이·밑위 | 허리밴드 아래에서 시작 | 기존 아웃심/직선 밑위와 구분 |
| 스커트 길이·힙 | 밴드 아래 총장, 허리선 약 20cm 아래 힙 | 밑위/바지 아웃심 생성 금지 |

가이드가 단면의 2배라고 명시한 둘레는 해당 측정 위치를 일치시킨 뒤에만 변환할 수 있다. 로더는 숫자를 임의로 반으로 나누거나 앱의 기존 측정 키로 확정하지 않는다. 비해당 `0.0`과 null은 0cm 정답으로 학습하지 않는다. 원본 Polygon은 마스크이며 어깨 봉제선 좌표가 아니다.

## 실행한 학습과 평가

`ml/config-aihub-mask-pretrain.json`으로 프로젝트 자체 spatial v2 모델을 무작위 초기화해 **Metal GPU 5에포크**, **780스텝**, **12,410회 이미지 노출**을 실행했다. 실제 사용한 고유 사진은 **2,482장**, 합성 사진은 **0장**이다. 학습 항목은 분류·마스크이며 실제 봉제선/치수 회귀 학습은 **0장**이다. cm 원본은 `source_measurements.jsonl`에 추적 가능하게 보존했다.

최종 가중치: `ml/artifacts/aihub-coat-jacket-mask-pretrain-v2/checkpoint.pt`.
SHA-256: `0baeadd24aeb788b1a575c3f4762643b1b6a1b8b486d84ec1ceb0fb9cae96ddf`.
최초 v1 실행은 승인 수량을 고정하기 전 2에포크 후 중단했고 최종 수치에 합산하지 않았다. 최종 v2는 고정된 레지스트리/원본 manifest로 5에포크를 완료했다.

같은 학습 사진에 대한 마스크 IoU는 코트 0.9381/재킷 0.9255다. **학습 세트 점검값이며 일반화 정확도가 아니다.** 독립 실제 검증 사진 0장, 실제 랜드마크 PCK/NME와 cm MAE/P95는 미검증이다. 모델이 치수 측정에 완성됐다고 해석하면 안 된다. 앱/서버 배포 승인도 false다. 재현 수치와 카테고리별 결과는 `ml/reports/AIHUB_71501_TRAINING.json`에 있다.

## 권리와 재현 명령

현재 약정은 출처 표시를 전제로 학습한 제품/서비스의 영리 활용을 허용하지만, 원본 제3자 열람·제공 및 국외 반출은 제한한다. `AI-Hub-71501-2026-10-28`은 검토한 별도 약정이며 CC BY로 추정한 것이 아니다. 승인 범위는 승인 사용자의 한국 내 로컬 학습·전처리다. 원본 재배포, 제3자 AI 사진 전송, 미승인 국외 이전 및 앱/서버 가중치 배포는 승인하지 않았다. 원본 사진·JSON·파일별 치수는 Git에 넣지 않았다. 로컬 감사에는 이미지와 라벨 각각의 SHA/출처가 있으며 Git에는 집계와 아카이브/모델 핀을 남겼다.

```sh
cd ml
uv run python -m coordit_ml registry
uv run python -m coordit_ml audit-aihub artifacts/aihub71501/real artifacts/aihub71501/new-audit
uv run python -m coordit_ml convert-aihub aihub-conversion.json
uv run python -m coordit_ml validate artifacts/aihub71501/approved-v1/records.jsonl
uv run python -m coordit_ml train config-aihub-mask-pretrain.json
uv run python -m coordit_ml evaluate artifacts/aihub-coat-jacket-mask-pretrain-v2 artifacts/aihub71501/approved-v1/records.jsonl --split train
```

변환/학습 재실행은 기존 결과를 덮어쓰지 않는다. 새 output 경로를 사용하거나 학습 재개 시 epochs를 늘리고 `resume:true`로 설정한다. 데이터/레지스트리 핀이 바뀌면 기존 체크포인트를 억지로 재개할 수 없다. 점검 전용 `audit-aihub`의 승인 수 0은 이 명령이 권리를 부여하지 않는다는 뜻이며 승인 변환 결과 수량과 구별한다.

현재 코트/재킷 사진의 마스크 사전학습은 끝났지만, 실제 봉제선 자동화는 **원본 사진에서 측정 프로토콜에 맞는 좌표 주석**을 확보해야 한다. 숫자 치수만으로 픽셀 정답을 꾸며내지 않는다. 정확도 출시는 별도 줄자/AR 독립 시험으로 판단한다. Phase 3는 계속 보류한다.
