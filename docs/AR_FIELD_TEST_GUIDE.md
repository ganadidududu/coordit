# 휴대폰 AR 실측 시험 안내

2026-10-27. 우선순위는 실제 봉제선/측정점의 위치와 cm 수치다. Phase 3는 변경하지 않았다.

2026-10-28 촬영 준비 단계·평면 경계·인식 중단/직접 입력·보정점 보존 수정과 AI Hub 실제 치수 데이터 조사 내용은 [후속 기록](AIHUB_71501_AND_AR_FEEDBACK.md)을 참고한다. 아래 설치 이력은 10월 27일 빌드의 기록이며 후속 수정이 폰에 자동 반영되는 것은 아니다.

## 설치와 단독 실행

goofy(iPhone 15 Pro)에 **Coordit AR Test**를 별도 앱 ID `com.insihwan.coordit.arfieldtest`로 설치했다. 사용자가 개발자 신뢰를 완료하고 AR 시험 화면이 열린 것을 확인했다. 이후 기록 버튼/접근성/실패 기록 개선이 포함된 최종 빌드도 같은 테스트 앱에 설치했다. 기존 운영 앱·팀·기능 플래그는 변경하지 않았다.

홈 화면에서 앱을 열면 시험 화면으로 직접 들어간다. **시험 중 Mac·케이블·Xcode·ML 서버가 필요하지 않다.** AR 평면, 로컬 윤곽점과 수동 보정으로 시험하며 분석 API·옷장 저장·결제 차감은 호출하지 않는다. 광고 동의 요청도 이 시험 진입점에서는 실행하지 않는다. 개인 개발팀 프로필의 현재 만료 시각은 **2026-11-03 17:30:14 KST**다. 만료 후에는 Mac에서 재서명/설치해야 한다. 이는 이번 프로필의 실제 값이며 모든 프로필의 공통 만료일이 아니다.

재설치가 필요하면 폰 잠금을 풀고, 개발팀/기기를 지정한다. 공개 저장소에 비밀번호·인증서 개인키를 넣지 않는다.

```sh
scripts/run-ar-field-test-ios.sh <TEAM_ID> <DEVICE_UDID>
```

스크립트는 임시 프로젝트 사본에만 새 앱 ID, 시험 진입 플래그, 별도 빈 시험 entitlements를 설정한다. 개인팀에서 지원하지 않는 원래 Apple 로그인/공유 그룹은 이 독립 시험 앱에서 쓰지 않는다. 원래 Xcode 프로젝트의 권한은 그대로다. 임시 빌드/설치 로그 위치를 출력하며 임의로 지우지 않는다. Apple 계정·약관·키체인 승인·개발자 앱 신뢰는 필요한 경우 사용자가 기기/OS에서 직접 처리한다. 케이블은 최초 연결/문제 해결에 편리하며, 페어링된 무선 연결도 가능하다. [Apple 무선 기기 실행 안내](https://help.apple.com/xcode/mac/current/en.lproj/dev3e2f4ee6d.html).

## 세 방식

- **카드 없이 AR:** ARKit 월드 트래킹과 수평면을 사용한다. `sceneDepth`를 활성화하지 않는 경로다. Pro 기기 시험만으로 비-LiDAR iPhone의 정확도가 검증되지는 않으므로 비-LiDAR 실기기도 별도 평가해야 한다.
- **LiDAR:** 깊이 정보를 쓰는 기존 별도 경로다. 이번 첫 시험은 카드 없이 AR로 한다. 시험 수집기는 사진의 같은 프레임을 비교하는 AR 평면/카드 경로를 중심으로 사용한다.
- **카드:** 알려진 카드 크기로 환산하는 기존 경로다. 이후 같은 의류로 비교하되 결과 방법을 섞어 평균 내지 않는다.

현재 시험 앱의 자동점은 **로컬 윤곽 휴리스틱**이다. 학습된 v2 봉제선 모델이 휴대폰에서 실행되는 것이 아니다. 실제 봉제선과 윤곽의 바깥 끝은 다를 수 있다. 합성 모델 점수와 이 앱의 실물 정확도는 별개로 기록한다.

**실제 cm 정답으로 사이즈 수치를 예측하는 모델을 학습한 상태가 아니다.** v2가 학습한 것은 합성 랜드마크·마스크·분류이며, 생성된 cm 필드를 직접 회귀 손실에 사용하지 않았다. 실제 사진 14,101장에는 분류 정답만 있고, aRTF 원래 점도 Coordit 봉제선 정답으로 바꾸지 않았다. 실제 봉제선 자동 인식을 완성하려면 권리가 확보된 별도의 실제 학습용 측정점 라벨이 필요하다. 이 앱으로 모으는 독립 평가용 줄자/보정 기록은 자동으로 그 학습에 재사용하지 않는다.

## 먼저 9회 시험

처음에는 티셔츠·팬츠·스커트 각 1벌을 3번씩 **새로 촬영**한다. 부담되면 티셔츠 1벌 × 3회부터 시작한다. 같은 사진의 점을 여러 번 움직인 것은 반복 촬영으로 세지 않는다.

1. 줄자로 실제 옷을 잰다. 옷은 당기지 않고 평평하게 편다. 두 번 재서 값이 다르면 측정 기준을 다시 맞춘다. 가슴·허리·힙은 **둘레가 아닌 단면**이다.
2. 앱 상단에서 종류를 선택한다. `시험 정보 입력`에 같은 실물의 고정 ID(예: `tshirt-01`), 배경, 조명, 부위별 줄자 정답을 입력한다. 조명 칸에는 필요하면 `밝은 실내 / 높이 약 1m / 정면`처럼 조건도 함께 적는다. 실제 학습에 쓰지 않은 독립 의류일 때만 독립 평가 체크를 켠다.
3. `카드 없이 AR`를 선택한다. 바닥/테이블에 옷을 펴고 전체가 보이게 한다. 카메라를 천천히 움직여 평면을 인식한 뒤 잠깐 고정하고 촬영한다. 버튼이 활성화되지 않으면 실패를 기록하며 억지로 값을 만들지 않는다.
4. **점을 건드리기 전에 `자동점 / 실패 기록`**을 누른다. 첫 자동 결과는 내부에 고정되므로 이후 보정 결과로 바뀌지 않는다. 자동 검출이 실패했어도 기록한다.
5. 실제 측정 기준에 맞게 점을 끌어 보정한다. 점이 없으면 `직접 보정 → 옷 측정점 직접 지정`을 사용해 순서대로 찍는다. 확대 후 점을 움직일 수도 있다. 모든 부위가 맞으면 `보정 / 실패 기록`을 누른다. 보정도 실패했다면 실패 상태를 그대로 기록한다.
6. `다음 시도`로 새로 촬영한다. 같은 옷은 같은 ID와 줄자 정답을 유지한다. 자동/보정 한 쌍의 의류 ID·정답·총장 기준을 중간에 바꾸면 기록을 거부한다.
7. 종료 전에 **내보내기**를 눌러 파일 앱의 원하는 로컬 위치에 JSON을 저장한다. 기록은 앱 메모리에 있으므로 앱 종료/강제 종료 전에 반드시 내보낸다. 같은 기록이 포함된 이전/최신 내보내기를 함께 평가하면 중복 시도로 거부된다. 세션별 최신 파일 하나씩 사용한다.

시험용 서버 사진 전송이나 자동 학습 동의는 없다. JSON에는 cm·2D/3D 점·프레임·내부 파라미터·포즈·안정성·기기 모델·입력 조건을 기록하며 원본 사진, GPS, 로그인 토큰은 포함하지 않는다. 사용자가 저장한 시험 결과는 평가 목적이며 학습 로더의 승인 데이터로 자동 유입되지 않는다.

## 결과 계산

Mac으로 가져온 JSON 하나 또는 세션별 최신 JSON들이 있는 폴더를 입력한다. 출력은 새 디렉터리여야 한다.

```sh
uv run --directory ml python -m coordit_ml field-report /absolute/path/to/exports /absolute/path/to/new-results
```

`automatic.csv`, `manual.csv`, `report.json`이 생성된다. 자동과 보정을 나누어 방법/카테고리/부위별 MAE·중앙 오차·P95·Bias·성공률·재촬영률을 계산한다. 시뮬레이터/합성·독립성 미확인·중복 시도·같은 촬영에서 바뀐 정답/프레임·스커트의 바지 부위·3D 점 거리와 다른 cm는 거부한다. 자동/수동 점의 위치 차이는 **보정 이동량**으로 보고하며 독립 랜드마크 정답 PCK로 부풀리지 않는다. 실패 값은 null로 남겨 분모에서 누락하지 않는다. 한 부위가 유효하지 않은 완성되지 않은 측정은 보수적으로 해당 단계 실패로 수집한다.

처음 9회는 큰 오류를 찾는 시험이다. 운영 정확도를 판정하려면 **각 카테고리/부위에 성공한 독립 의류 최소 20벌**, 다양한 기기/조건에서 반복 측정, 부위별 MAE ≤1 cm·P95 ≤2 cm·성공률 ≥95%가 필요하다. 한 기기·한 옷의 반복만으로 의류 수를 채우지 않는다. 조건별 편향도 원본 JSON/CSV로 나누어 검토해야 한다. 현재 이 실제 cm 목표는 미검증이며 보고 도구도 `deployment_approved=false`를 유지한다.

## 현재 모델 점수의 정확한 범위

v2 전체 합성 **1,320장(11종 ×120)** 중 **학습 1,108 / 검증 110 / 테스트 102장**이다. 학습에는 실제 aRTF 524장도 포함되어 총 1,632개의 고유 학습 이미지가 사용됐다. aRTF 원래 키포인트를 봉제선 정답으로 변환하지 않았다. 두 모델을 각각 35 epoch 실제 학습했고 각 실행의 노출 수 55,370회는 독립 이미지 수가 아니다. 더 이전 v1 합성 330장과 v2를 합쳐 이 학습 수로 보고하지 않는다.

| 역사적 실험 | 합성 평가 장수 | 이미지 평균 PCK@0.05 | 이미지 평균 NME |
|---|---:|---:|---:|
| v2 공유 헤드, 검증 | 110 | 100% | 0.00402552 (0.4026%) |
| v2 공유 헤드, 테스트 | 102 | 99.8775% | 0.00381863 (0.3819%) |
| v2 카테고리 헤드, 검증 | 110 | 98.75% | 0.00650979 (0.6510%) |

정규화된 정사각 입력 좌표의 L2 거리를 대각선 `sqrt(2)`로 나눈다. PCK 허용 반경은 그 대각선의 **5%**다. 이미지별 점 평균을 계산한 뒤 이미지 수로 합산한 값이며 모든 점을 모은 pooled PCK와 구분한다. **100% PCK는 실제 1 cm 오차 보장이 아니다.** 단순한 절차적 합성 형태에서의 결과이므로 실제 봉제선 PCK/NME와 실물 cm MAE/P95는 모두 아직 미검증이다.

정확한 소스 보고서, 체크포인트/manifest hash와 부위별 데이터는 `ml/reports/SPATIAL_V2_LANDMARK_SUMMARY.json`과 `spatial-v2-*.json`에 있다. 추가 실제 사진 14,101장은 분류 주석만 있으며, 실제로 새로 실행한 것은 2 CPU step/8개 사진 노출의 입력 스모크다. 이 사진으로 봉제선 모델 재학습을 완료했다고 주장하지 않는다. 레지스트리 변경으로 이전 연구 가중치는 현재 로더에서 거부되며 앱/서버 배포 목록은 계속 비어 있다.
