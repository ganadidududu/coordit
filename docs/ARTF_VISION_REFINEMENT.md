# aRTF 봉제점 확대 재검토 실험 — 2026-10-29

이 문서의 `visible_only_ar_usable`은 실험 당시의 보수적인 좌표 사용 기준이다. 이후 사용자 요청에 따라 [시험 UI](HOSTED_AR_FIELD_TEST.md)는 불확실한 점도 수정 가능한 초안과 초안 cm로 표시하도록 변경했다. 점수 계산과 정답률은 바꾸지 않았으며, 초안 표시를 봉제점 자동 검출 성능 향상으로 집계하지 않는다.

추가 유료 API 요청은 사용자의 예산 절약 지시에 따라 중단했다. 아래 결과는 이미 저장한 응답만 오프라인으로 평가했다. 자동 재시도·추가 결제·다른 모델 호출은 진행하지 않는다. **Phase 3는 변경하지 않았다.**

## 범위와 방법

이번 작업은 모델 재학습이 아니라 Astra/Gemini의 기존 사진 추론 방법 비교다. 기존 체크포인트와 앱의 추론 경로는 변경하지 않았다. 모델별 첫 응답을 보존하고, 원본과 **모델 스스로 제안한 좌표로 만든 3배 확대 크롭**을 함께 보여 한 번만 재검토했다. 정답 좌표·정답 bbox·점수는 요청에 넣지 않았다. 확대는 원본 해상도를 높이지 않는다.

- 공개 aRTF 개발 사진 8장: 티셔츠 4장, 반바지 4장. 기존 응답을 재사용했다.
- 추가 평가 사진 16장: 티셔츠 8장, 반바지 8장. 개발 사진의 location 4–9와 겹치지 않는 location 2–3에서 카테고리/장소별 4장씩 해시로 선정했다. SHA 중복을 제거하고 개발/선정 사진과 pHash Hamming 거리를 8 이상으로 제한했다. 선정에 정답 좌표나 모델 응답을 사용하지 않았다.
- 원본은 512×256. 상의 어깨 좌우/겨드랑이 좌우, 반바지 허리 좌우/가랑이/왼쪽 바깥 밑단의 공통 4개 지점만 평가했다. 실제 측정용 전체 스키마나 다른 9개 카테고리를 검증한 실험은 아니다.
- AI Hub 사진 전송 0장, 새 학습 이미지 0장, 새 가중치 0개.

개발 8장에서 크롭 좌표 출력과 원본 좌표 출력을 각각 비교했다. 원본 좌표를 반환하는 재검토 방식을 추가 평가에 사용했다. 크롭 좌표에는 정확한 역변환을 적용하고 원본 좌표에는 다시 변환하지 않는다. 불확실성을 확신으로 바꾸거나 정답으로 좌표를 수정하지 않는다.

추가 16장 모두에서 첫 추론은 완료했다. 재검토는 Astra 9장, Gemini 13장만 완료했다. 예산 사전 거절 및 사용자 중단으로 남은 각각 7장/3장은 **미실행**이며 모델의 오검출/기권으로 점수에 넣지 않았다. 모델별 전후 비교는 동일 사진이 완료된 부분집합만 사용했다. 이 두 부분집합은 서로 다르므로 재검토 점수를 모델 간 순위로 해석하면 안 된다.

## 정확도

PCK@0.05와 NME는 이전 보고서와 같은 정규화 사각 입력 대각선 기준이다. NME는 **좌표를 제공한 점만** 계산하므로 제공률과 함께 봐야 한다. JSON에는 기권에 1을 부과한 별도 지표와 원본 픽셀/원본 대각선 기준 지표도 보존했다. 두 좌표 정규화를 혼용하지 않는다.

**불확실한 좌표를 포함한 분석용 점수:**

| 평가 | 사진 / 가시 정답 점 | 첫 추론 PCK → 재검토 PCK | NME → 재검토 NME | 좌표 제공률 전 → 후 |
|---|---:|---:|---:|---:|
| Astra 개발 | 8 / 30 | 86.67% → 93.33% | 0.03011 → 0.01440 | 100% → 96.67% |
| Gemini 개발 | 8 / 30 | 76.67% → 66.67% | 0.04260 → 0.05260 | 100% → 93.33% |
| Astra 추가 평가, 부분 완료 | 9 / 31 | 58.06% → 70.97% | 0.06542 → 0.04235 | 100% → 100% |
| Gemini 추가 평가, 부분 완료 | 13 / 44 | 65.91% → 59.09% | 0.03680 → 0.05284 | 93.18% → 93.18% |

**앱이 거절하는 uncertain_proposal을 제외한 점수:** 가시 정답 전체를 분모로 유지한다. 이는 모델의 `visible_proposal` 상태에 따른 좌표 사용 가능성으로, AR 평면·cm 정확도까지 통과했다는 뜻은 아니다.

| 부분 완료 평가 | PCK 전 → 후 | 제공 좌표 전 → 후 | 조건부 NME 전 → 후 |
|---|---:|---:|---:|
| Astra, 9장 / 31점 | 25.81% → 35.48% | 14/31 → 14/31 | 0.07552 → 0.03366 |
| Gemini, 13장 / 44점 | 52.27% → 45.45% | 32/44 → 31/44 | 0.03210 → 0.05108 |

두 모델 모두 첫 추론을 끝낸 **동일한 추가 사진 16장 / 가시 정답 55점**에서는 Astra의 전체 제안 PCK 63.64%, NME 0.05747, 제공률 100%; Gemini는 67.27%, 0.03517, 94.55%였다. 불확실 좌표 제외 PCK/제공률은 각각 Astra 29.09%/43.64%, Gemini 56.36%/78.18%다. 개발 8장의 90%대 점수를 일반 성능으로 제시할 수 없다.

## 길이 오차와 채택 여부

다음은 **불확실 좌표까지 포함한** 동일 사진 내 투영 선분의 평균 상대오차다. 실제 cm나 AR 센서 오차가 아니다. 반바지 아웃심은 문서화된 동일 측면 `waist_left`–`side_hem` 쌍만 사용하며 밑위/인심을 임의로 만들지 않는다.

| 모델별 부분 평가 | 어깨 | 겨드랑이 단면 | 허리 | 아웃심 |
|---|---:|---:|---:|---:|
| Astra 9장, 전 → 후 | 31.83% → 31.17% | 5.25% → 4.93% | 14.64% → 3.19% | 1.30% → 1.14% |
| 제공 쌍 / 정답 쌍, 전후 동일 | 3/3 | 2/2 | 4/4 | 5/5 |
| Gemini 13장, 전 → 후 | 8.00% → 8.00% | 6.85% → 7.02% | 7.62% → 8.19% | 6.36% → 8.49% |
| 제공 쌍 / 정답 쌍, 전후 동일 | 2/3 | 4/4 | 5/5 | 7/7 |

Astra는 일부 지점과 허리 선분이 개선됐지만 어깨 오차가 크다. 특히 불확실 좌표를 제외하면 Astra 어깨 쌍은 전후 모두 **0/3**이다. 재검토는 실제 사용 가능한 측정 전체를 해결하지 못했다. Gemini 재검토는 전반적으로 악화되어 앱에 적용하지 않는다. Astra도 부분 평가와 제공률 한계 때문에 자동 적용하지 않는다. 앱의 기존 단일 요청 경로를 보존하여 두 번째 API 비용이 자동 발생하지 않는다.

## 비용·시간·실행 이력

이번 작업에서 새로 완료한 추론은 86회, HTTP 요청은 사전 거절 2회를 포함해 88회다. 저장된 성공 응답 `usage.cost` 합계는 **$1.39460650**이다. 과거 개발 사진 첫 추론 비용은 새 비용에 중복 합산하지 않았다. 이번 비용은 별도 청구 원장 대조를 하지 않았으며, 거절 응답에는 생성 ID/usage가 없어 비용 0이라고 임의 확정하지 않는다.

| 실행 | 성공 추론 | 저장된 usage.cost 합계 |
|---|---:|---:|
| 개발 크롭 좌표 재검토 | 16 | $0.28653800 |
| 개발 원본 좌표 재검토 | 16 | $0.27869100 |
| 추가 16장 첫 추론 | 32 | $0.50480475 |
| 추가 사진 원본 좌표 재검토, 부분 완료 | 22 | $0.32457275 |

부분 완료 사진의 평균 HTTP 응답 시간은 Astra 재검토 9.59초 / 첫 추론 포함 합계 24.45초, Gemini 4.21초 / 합계 11.98초였다. 사진 업로드 준비·모바일 전송·AR 인식 시간은 제외했다.

초기 계획에는 새 유료 호출 한도 80회가 기록돼 있었다. 개발 단계 원본 좌표 비교 16회를 추가하면서 실제 성공 호출이 86회가 되어 이 계획을 초과했다. 해당 변경을 초기 계획대로 실행했다고 주장하지 않는다. 추가 평가 점수를 본 뒤 프롬프트를 튜닝하거나 좋은 응답을 골라내지 않았다. 두 차례 HTTP 402 뒤 별도 출력 폴더에서 진행한 이력이 있으며, 사용자 예산 중단 이후에는 추가 호출하지 않았다. 로컬 기록과 비용은 `ml/reports/ARTF_VISION_REFINEMENT_EXECUTION.json`에 남겼다.

## 증거와 오프라인 재현

원본/크롭/응답/설정/요청 해시는 Git 제외 경로 `ml/artifacts/artf-vision-refinement-v3/`에 있다. 기존 체크포인트를 덮어쓰지 않았다. 추론을 다시 호출할 필요 없이 다음 명령으로 부분 결과의 사진·요청 해시·좌표 역변환과 점수를 재검사할 수 있다. 출력은 기존 파일과 다른 경로를 사용한다.

```sh
cd ml
uv run python -m coordit_ml.vision_refinement_cli score \
  --config artifacts/artf-vision-refinement-v3/holdout-original-recovered.json \
  --output artifacts/artf-vision-refinement-v3/offline-replay.json --partial
uv run pytest -q
uv run ruff check coordit_ml tests
uv run basedpyright
```

`score`는 API를 호출하지 않는다. `prepare`는 공개 카탈로그를 조회하고 `run`은 유료 호출을 수행하므로 예산 중단 상태에서는 실행하지 않는다. 자동 재시도·중단 실행 자동 재개는 없다. 전체 그리드 검증이 기본이며 `--partial`을 명시해야 일부 결과를 평가한다. 미실행과 모델 기권, 예산 사전 거절을 구분하고 중복/다른 사진/변경된 요청을 거절한다.

검증: ML **120개 테스트 통과**, Ruff 통과. 변경한 Python 파일은 basedpyright 0 errors/0 warnings, 전체 프로젝트는 0 errors/기존 Torch·ONNX 관련 28 warnings다. 두 개발 실험과 부분 평가를 실제 CLI로 오프라인 재생했다. 이번 작업에서는 앱·센서 코드를 바꾸지 않아 iOS/Android/실기기 테스트를 새로 실행하지 않았다.

## 해석·권리 한계

추가 사진은 개발 8장과 이미지/장소를 분리했지만, 원본 의류 ID가 미해결이므로 물리적으로 다른 옷이라는 보장은 없다. 이 publisher test 계열의 일부 이미지는 과거 윤곽 알고리즘 개발에 사용됐고 상용 모델의 사전학습 노출 여부도 모른다. 완전히 새로 확보한 독립 평가 세트라고 부르지 않는다. 출판자 랜드마크는 검수된 봉제선/cm 정답이 아니다. 치수 MAE/P95, mIoU와 전체 11개 카테고리 성능은 이번 실험에서 측정하지 않았다.
