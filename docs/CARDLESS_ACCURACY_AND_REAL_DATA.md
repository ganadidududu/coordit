# AR 수치 정확성 우선 작업 및 실제 데이터 확보 (2026-10-27)

후속 실기기 시험 준비: [휴대폰 단독 실행·줄자 시험 절차·합성 PCK/NME](AR_FIELD_TEST_GUIDE.md). 별도 iPhone 시험 앱과 로컬 JSON 평가 CLI가 추가됐다. 실제 cm 오차 검증 완료를 뜻하지 않는다.

사용자의 최신 우선순위는 **올바른 측정 랜드마크를 AR 평면에 투영해 정확한 cm를 얻는 것**이다. 세부 분류 성능은 그 다음이다. 작업은 기존 `codex/camera-auto-guides`에서 이어갔고, Phase 3는 변경하지 않았다. 기존 아키텍처·학습·API·실행 명령은 [이전 Phase 0–2 기록](CARDLESS_PHASE_2_STATUS.md)에 남아 있다. 이 문서는 그 이후의 실제 변경과 검증 한계를 기록한다.

ML은 **24/24 테스트**, Ruff, 타입 오류 0개(의존성 스텁 경고 27개), no-excuse 위반 0개다. 추적 출처 inventory **16,275개**(aRTF 524 + 합성 1,650 + 신규 실제 14,101)의 감사가 통과했다. 로컬 로그는 `/tmp/coordit-real-data-evidence/`에 있다.

## 실제로 확보한 데이터와 권리 범위

[Clothing Dataset for Second-Hand Fashion v3 원본](https://zenodo.org/records/13788681)은 RISE/Wargön Innovation/Myrorna의 자체 수집과 전문가 의류 종류 주석, CC BY 4.0을 명시한다. [원저자 글](https://fnauman.com/second-hand-fashion/posts/2025-02-06-data-exploration/)에서 직접 연결하는 [front-only RGB 데이터](https://huggingface.co/datasets/fnauman/fashion-second-hand-front-only-rgb)를 사용했다. 일반 업로더의 라이선스 배지만 근거로 승인하지 않았다.

원저자 저장소 revision `b2559ac0157ea9b6913a65062877f487952e690b`의 **14개 parquet 파일을 실제 다운로드**하고 LFS SHA-256·크기를 모두 검증했다. 약 2.8 GB의 front-only 파생본이며, 원본 Zenodo 26.8 GB ZIP을 다운로드했다고 주장하지 않는다. 파일은 총 31,638개 front 사진을 담고 있으며 이 중 publisher test 3,390개는 학습·시각 분류 검토에서 제외했다. 변환기는 중복 126장과 비대상/모호한 종류를 제외해 **14,101장**을 수용했다. 원본 해시·경로·촬영일·샤드 pin·변환 후 해시를 유지하고 불필요한 메타데이터는 제거한다. Git에는 사진이나 가중치를 넣지 않는다.

별도로 aRTF 보조 타월 210장, 합성 v1/v2는 각 제품 카테고리당 30/120장이다. 신규 사진의 **실제 마스크·봉제선 랜드마크·cm 정답은 모두 0개**다. 사진 속 격자나 EXIF를 줄자 정답처럼 취급하지 않았다. Sweater/Outerwear 전체를 각각 스웨트셔츠/코트로 일괄 오분류하지 않았으며, 13개의 약한 세부분류는 hash와 별도 검토 사유를 기록했다. 분류만 잘되는 것을 실측 개선으로 보고하지 않는다.

촬영일과 유사 사진의 보수적인 그룹화가 전체 풀을 연결하므로 이 신규 풀은 **전부 training-only**다. 검증/테스트를 임의로 나눠 독립 성능을 만들지 않았다. 기존 aRTF 평가 계열 980장과 새 publisher test 3,390장은 학습에 포함하지 않았다. 독립 실제 cm 평가용 의류는 별도로 확보해야 한다.

승인·원저자 권한 근거·이미지/주석/약관/수정·배포 범위는 `DATASET_LICENSES.md`, `THIRD_PARTY_NOTICES.md`, `ml/registry/reviews/secondhand-v3-front.json`에 분리했다. CC BY 4.0 저작자 표시 의무를 유지한다. 이 출처 검토는 원저자 공개 진술에 근거하며 운영 전 법률 검토를 대신하지 않는다. NTNU의 CC BY-SA 데이터와 원본별 권한을 완전히 확인하지 못한 다른 후보는 미승인 상태로 남기고 학습하지 않았다.

## 학습 및 남은 정확도 작업

새 데이터는 `segmentation_supervised=false`, 빈 semantic keypoint/실측 정답을 가진다. 두 모델 아키텍처 모두 없는 마스크/봉제선 정답에 역전파하지 않는 테스트를 추가했다. 평가에서 없는 주석을 IoU/PCK의 정답이나 분모로 쓰지 않는다. source pin을 바꿔 미검토 이미지 미러로 대체하면 변환이 실패한다. 유사 이미지 검색은 반경 4 Hamming 후보 인덱스를 사용하며 완전 탐색과 일치하는 회귀 테스트가 있다.

CPU에서 신규 실제 풀을 읽어 v2 **2 step / 8개 실제 사진 노출**의 입력·감사·역전파 스모크를 실제 수행했다. 체크포인트는 로컬 `ml/artifacts/secondhand-supervision-smoke/checkpoint.pt`이고 hash와 log 요약은 `ml/reports/MODEL_RUNS.json`, `ml/registry/MODEL_ARTIFACTS.json`에 있다. 이는 분류 데이터 입력 검증으로, 랜드마크 모델 학습 완료나 성능 향상이 아니다. 이번에 신규 전체 GPU 학습을 했다고 주장하지 않는다. 이전 35-epoch MPS 모델 결과는 이전 기록에 그대로 남겼다.

데이터 레지스트리가 바뀌었으므로 이전 연구 체크포인트는 현재 registry hash 검사에서 거부된다. 과거 학습 메타데이터를 새 승인으로 덮어쓰지 않았다. 신규 스모크도 배포 승인이 없으며 앱/서버 배포 가중치 목록은 비어 있다.

이제 남은 핵심은 세부 분류 확대보다 **독립적인 실제 봉제선·줄자 정답과 실기기 AR 반복 평가**다. 실제 기기/의류가 제공되지 않은 환경에서 이를 완료했다고 표시할 수 없다. 11종의 부위별 최소 20벌 이상 독립 의류, 다양한 기기·거리·배경·조명·기울기에서 자동점과 수동 보정을 나누어 기록해야 한다. 모든 실패/재촬영도 기록하고 기존 카드 측정과 같은 의류로 비교한다. 부위별 MAE ≤1 cm·P95 ≤2 cm 및 기존 성공률 게이트를 충족하기 전에는 운영 활성화하지 않는다. 특히 두꺼운 소재·주름·바닥과 의류 면의 높이 차이는 평면 투영의 실제 편향을 만들 수 있어 현실 평가가 필요하다.

재현 명령은 `ml/README.md`의 `download-secondhand`, `convert-secondhand`, `validate`, `audit-inventory`, `config-secondhand-smoke.json`과 이전 단계의 앱/서버 명령을 따른다. 기존 출력은 덮어쓰지 않으므로 재실행은 새 출력 디렉터리를 지정한다. **Phase 2의 개발 구현은 진행됐지만 상업적 실측 검증 완료는 아니다. Phase 3는 계속 보류한다.**
