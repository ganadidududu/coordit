# Public aRTF visual-assistant pilot protocol v1

Use only the eight frozen original PNG photographs named P01–P08 in the public aRTF packet. No AI Hub pixels, original labels, label overlays, prior model predictions or per-photo errors are to be shown before proposals are saved. Category and source dimensions may be supplied. The first 32 publisher records of each category were excluded before hash-based sampling to avoid previously inspected early examples. Do not choose or replace an image based on its difficulty or outcome.

This execution is the current chat assistant's visual interpretation, not a separately invoked provider API or a revision-pinned reproducible model run. Exact provider model revision is unavailable. It is a single interactive pilot, not independent annotation or human-verified ground truth. The user authorized external use of public aRTF photographs only.

Return one normalized (x,y) per requested landmark, origin top-left, x/512 and y/256, without crop or mirror. Status is visible_proposal, uncertain_proposal or abstain. Abstain requires null x and y. Never invent an invisible junction or output centimeters. A visible but ambiguous candidate may be uncertain_proposal and is still scored; confidence does not remove errors.

T-shirt targets: shoulder_left, shoulder_right, armpit_left, armpit_right. Locate the shoulder/sleeve attachment and underarm junctions rather than the cuff's outermost point. The publisher's side is the whole-garment side whose lower waist/hem endpoint is nearest the garment bbox bottom-left in original pixel distance. It is not wearer anatomy or independently x-sorted shoulder/underarm pairs. If this side reference is ambiguous, state the uncertainty.

Shorts targets: waist_left, waist_right, crotch, side_hem. Waist-left is the waist endpoint nearest the garment bbox top-left in original pixel distance. Crotch is the inseam junction. side_hem is the corresponding left pipe's outer hem endpoint. The duplicate Coordit side_waist alias is omitted from this pilot's point metrics for every participant; waistband width is evaluated using waist_left/right.

Save all eight proposals with packet/protocol SHA before loading ground truth for scoring. Do not revise a prediction after seeing a label or score. The proposal file is never imported into training. Evaluate every visible publisher GT target in the predeclared target sets; missing external coordinates count as PCK failures and are reported with coverage and an explicit upper-bound NME penalty. Also show NME conditional on a supplied coordinate. Never hide abstentions by reporting only the easy points.

Compare both existing pinned Coordit models on these exact photos and targets using raw coordinates regardless of predicted visibility. PCK@0.05/NME use the same normalized square-input diagonal as prior development reports. Report original-image projected pixel length and relative length errors for shoulder width, underarm width and shorts waist width, with failed-pair counts. These are not cm/AR accuracy, and publisher anatomical points are not certified tailoring-seam ground truth. Eight photos do not establish 90% production accuracy; public-model pretraining contamination and garment/session independence are unknown.
