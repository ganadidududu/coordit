# Model rights register

Hosted API benchmark (2026-10-28): five models were called through the user's authenticated OpenRouter account on eight public aRTF photos each. No hosted model weights were downloaded, bundled, licensed as open source, or approved for app/server release. Model/provider IDs, actual usage charges and independent generation-ledger checks are recorded in `ml/reports/ARTF_OPENROUTER_*`. These API results do not change existing local-checkpoint rights or deployability; API service conditions are separate from aRTF image rights. No AI Hub source image was sent. See `docs/ARTF_OPENROUTER_MODEL_BENCHMARK.md`.

The public-aRTF visual-teacher experiment adds separately pinned weak annotations generated by the current interactive chat assistant, **not** a downloaded teacher checkpoint or separately invoked revision-pinned provider API. Raw proposal bytes, annotation protocol, source images, preserved parent weights, training configuration and final result are recorded separately. The candidate and equal-budget no-teacher control remain internal research weights under the existing source restrictions, including AI Hub local-use limits. New unverified endpoint proposals do not become certified labels or production-supported landmarks. App/server artifact lists remain empty; no measurement or deployment approval is granted. See `docs/ARTF_VISUAL_TEACHER_TRAINING.md`.

Controlled high-resolution follow-up (2026-10-28): four additional internal Metal runs completed 20 epochs each with the same approved AI Hub masks, aRTF partial real landmarks and GCD geometry-derived synthetic points. New versioned 256/512 contracts keep old 128 checkpoints unchanged; 512 training was **not** executed. A 256 context variant adjusts convolution dilation without new parameters or external code/weights; the last run adds visible projected-pair supervision, not centimeter targets. All four weights remain local development artifacts under the same AI Hub restrictions and CC BY attribution obligations, with app/server lists empty. `ml/reports/SEAM_HIGHRES_RUNS.json` records exact parent/checkpoint/source hashes and sample counts. Development PCK remains about 22–25%, and projected chest-length error did not improve consistently; no model is promoted for measurement or release. Newly prepared AI Hub proposals are unverified and were not used as supervised seam truth.

Authority: `ml/registry/MODEL_MANIFEST.json`. App and server artifact lists are separate and currently empty. No third-party weights are bundled or downloaded.

[RF-DETR](https://github.com/roboflow/rf-detr) differentiates Apache-designated components/weights and Plus PML terms. All selected checkpoint candidates remain pending until their exact hash and lineage are reviewed. AGPL/NC weights are blocked by default.

Artifacts must carry architecture, category/landmark schema, training manifest hash, registry hash, checkpoint SHA-256, metrics and deployment approval. Torch pickle checkpoints are local trusted artifacts only; service loading must use `weights_only=True`.
